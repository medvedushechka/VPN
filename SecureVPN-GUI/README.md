## 🔍 Диагностика проблем

### Проблемы с подключением:

1. **Проверьте интернет** - приложение автоматически проверит
2. **Проверьте WireGuard** - должен быть установлен
3. **Проверьте права администратора** - могут потребоваться для VPN

### Коды ошибок:

- ❌ **Нет подключения к интернету** - проверьте сетевое подключение
- ❌ **Сервер VPN недоступен** - сервер может быть выключен
- ❌ **API сервер недоступен** - проблемы с авторизацией
- ❌ **Неверные учетные данные** - проверьте логин/пароль
- ❌ **WireGuard не установлен** - установите WireGuard

## 📱 Использование

### Первый запуск:
1. Приложение проверит подключение к серверу
2. Введите логин и пароль
3. После авторизации появится главный экран

### Подключение к VPN:
1. Нажмите "Использовать VPN"
2. Дождитесь подключения (статус изменится на "🔒 Подключено")
3. Ваш трафик теперь защищен

### Отключение:
1. Нажмите "Отключить VPN"
2. Статус изменится на "🔓 Отключено"

### Работа в трее:
- Приложение сворачивается в системный трей
- Двойной клик по иконке - показать окно
- Правый клик - контекстное меню

## 🔧 Технические детали

### Архитектура:
```
GUI App → API Server (авторизация) → VPN Server (подключение)
```

### Используемые технологии:
- **PyQt6** - графический интерфейс
- **Requests** - HTTP запросы к API
- **WireGuard** - VPN протокол
- **Threading** - асинхронные операции
- **Win32API** - интеграция с Windows

### Файлы конфигурации:
- `%USERPROFILE%/securevpn_client.conf` - конфигурация WireGuard

## 🚀 Автозапуск

Приложение автоматически добавляется в автозагрузку Windows:
- Папка: `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`
- Ярлык: `SecureVPN.lnk`
