# 🎨 SecureVPN GUI Clients

Графические клиенты для SecureVPN с красивым интерфейсом и простым управлением.

## 📱 Доступные платформы

### 💻 [Windows Client](./windows/)
- **PyQt6** интерфейс с Material Design
- **Системный трей** для работы в фоне
- **Автозапуск** с Windows
- **Один клик** подключения к VPN
- **Готовый EXE** файл для распространения

### 📱 [Android Client](./android/)
- **Material Design** интерфейс
- **Фоновый режим** с постоянными уведомлениями
- **Kivy + KivyMD** фреймворк
- **APK файл** для установки на Android
- **Поддержка Android 5.0+**

## 🔧 Быстрый старт

### Для пользователей:

#### Windows:
1. Скачайте `SecureVPN.exe` из папки `windows/dist/`
2. Запустите приложение
3. Введите логин: `Medvedushkaa`, пароль: `1q2w3e4r5t6y`
4. Нажмите "Использовать VPN"

#### Android:
1. Скачайте `securevpn.apk` из папки `android/bin/`
2. Установите APK (разрешите установку из неизвестных источников)
3. Запустите приложение
4. Введите те же учетные данные
5. Нажмите "ИСПОЛЬЗОВАТЬ VPN"

## 🛠️ Технические детали

### Архитектура:
```
GUI Client → HTTP API (авторизация) → VPN Server (подключение)
```

### Используемые технологии:

**Windows:**
- PyQt6 - GUI фреймворк
- Requests - HTTP клиент
- WireGuard - VPN протокол
- Win32API - интеграция с Windows

**Android:**
- Kivy - кроссплатформенный GUI
- KivyMD - Material Design компоненты
- Buildozer - сборка APK
- Plyer - доступ к Android API

## 🔍 Диагностика

### Общие проблемы:

**❌ Нет подключения к интернету**
- Проверьте сетевое подключение
- Приложение автоматически проверит доступность

**❌ Сервер VPN недоступен**
- Убедитесь что сервер запущен
- Проверьте IP адрес в конфигурации

**❌ Неверные учетные данные**
- Логин: `Medvedushkaa`
- Пароль: `1q2w3e4r5t6y`

### Windows специфичное:

**❌ WireGuard не установлен**
- Скачайте с https://www.wireguard.com/install/
- Установите и перезагрузите компьютер

### Android специфичное:

**❌ Не устанавливается APK**
- Разрешите установку из неизвестных источников
- Проверьте версию Android (минимум 5.0)
